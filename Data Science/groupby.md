데이터를 다양한 방식으로 집계하고 분석하는 데에 사용하는 함수로, 특정 컬럼을 기준으로 여러 그룹을 나누고, 각 그룹에 대해 다양한 내장 함수들을 적용 가능
df.groupby('메뉴').min() - 기본형(결과가 이상하면 문자열 컬럼 때문일 가능성이 높으니 괄호 안에 numeric_only=True 적기)
df.groupby(['원산지', '칼로리']).mean() - 기준이 2개 이상일 때는 리스트라서 꼭 대괄호를 써줘야 함

**groupby로 비율 구하기**
df['diff'] = (df['실제도착시간'] - df['예상도착시간']).dt.total_seconds()
df['지연여부'] = df['diff'] > 0 
이렇게 True 또는 False 컬럼을 만들고
df.groupby('결제종류')['지연여부'].mean()
이렇게 하면 True를 1, False를 0으로 처리하기 때문에 mean만 해도 결제종류별 지연비율을 구할 수 있다
