**1: 문제 정의**
-레이블(target)은 연소득 50000달러 이상인지 이하인지
-50000달러 이상일 확률을 csv 파일로 생성 (정확히 얼마인지를 예측하는 건 회귀)
-[[평가 지표]]는 ROC-AUC로

**2: EDA**
-일단 데이터를 불러오기 (주로 read_csv로)
-[[head, sample]]로 어떻게 생겼는지 대충 파악하기
-shape로 데이터의 크기 확인 (test에 target 컬럼이 추가된다면 어떻게 될지 예측하는 것이 목적이므로 train 데이터에 column이 하나 더 있는 게 정상)
-info로 자료형 확인
-describe로 숫자형 자료의 경우 최대, 최소, 사분위수, 평균 등을 직관적으로 확인 가능
범주형 자료의 경우 데이터 수, 카테고리 종류(unique), 최빈값(top)과 그 빈도(freq)를 직관적으로 확인 가능
-[[isnull]].sum으로 결측치 개수 확인
-value_counts로 이진 분류인지, 불균형 데이터인지 확인

**3: 데이터 전처리**
-결측치 처리: df.dropna 활용하여 결측치가 있는 행을 삭제하거나, df.dropna(axis=1)으로 결측치가 있는 컬럼 자체를 삭제하거나, fillna로 값을 채우는 식으로 처리한다
이 중 뭘 고르든 최종 성능이 좋으면 그게 좋은 방법이기 때문에 보통 성능을 높이기 위해서는 여러 번 시도를 해봐야 한다
-이상치 처리: df =df[df['age']>=0] 이런 식으로 age가 0 아래인 이상치들을 제거할 수 있다. IQR X 1.5로 판단하는 게 일반적이지만, 도메인 지식이 있다면 이상치를 더 잘 처리할 수도 있다.
-주의점: train 데이터에 전처리를 할 때 test 데이터에도 똑같이 해줘야 한다. 물론 train 데이터에서 행을 삭제했다고 test 데이터에서까지 삭제하면 안된다.

**4: 인코딩**
사람이 보기 편하도록 구성되어 있는 데이터를 머신러닝 모델에서 입력 데이터로 활용할 수 있도록 변환하는 과정
(1)One-Hot Encoding
컴퓨터가 이해할 수 있도록 범주형 데이터를 0과 1의 이진 형태의 숫자 벡터로 변환하는 기법
train_oh = pd.get_dummies(train)
test_oh = pd.get_dummies(test)
pandas에서 기본적으로 제공하는 기능
(2)LabelEncoder
문자열의 unique한 값을 숫자로 바꾸는 것(0과 1만 쓰는 게 아니라 새로운 문자가 나올 때마다 1,2,3,.... 늘려나가는 방식)
from sklearn.preprocessing import LabelEncoder
for col in cols:
	le = LabelEncoder()
    train[col] = le.fit_transform(train[col])
	test[col] = le.transform(test[col])
(3)Scaling
수치형 데이터의 범위를 조정하는 작업
설명 편의상 cols = ['age', 'education.num', 'hours.per.week' ... ] 인 수치형 컬럼을 활용 
-Min-Max Scaling
데이터를 0과 1 사이로 변환하는 것
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
train[cols] = scaler.fit_transform(train[cols])
test[cols] = scaler.transform(test[cols])
-Standard Scaling
데이터를 평균이 0이고 표준편차가 1인 분포로 변환하는 것 (표준정규분포는 아닐 수도 있음)
코드는 위의 코드에서 MinMaxScaler를 StandardScaler로만 바꾸면 됨
-Robust Scaling
A라는 데이터가 있으면 (A - 중앙값) / IQR로 변환하는 것
코드는 위의 코드에서 MinMaxScaler를 RobustScaler로만 바꾸면 됨

**5: 검증 데이터 나누기**
검증 데이터를 활용해 train 데이터만으로 미리 모델의 성능을 예측해보는 것으로, train_test_split을 활용함 (이름에 test가 들어가지만, train, validation 데이터를 나누는 데에 활용됨)
from sklearn.model_selection import train_test_split
X_train, X_val, y_train, y_val = train_test_split(train, y_train, test_size=0.2, random_state=0)
X_train.shape, X_val.shape, y_train.shape, y_val.shape (의도대로 잘 쪼개졌는지 확인)

**6: 머신러닝 학습**
이제 모델에 데이터를 넣으면 되는데, 모델별 활용 방법은 다음과 같다
(1)RandomForest (Classfier, Regressor)
from sklearn.ensemble import RandomForestClassfier
model = RandomForestClassfier()
model.fit(X_train, y_train)
(2)LightGBM
import lightgbm as lgb
model = lgb.LGBMClassfier()
model.fit(X_train, y_train)
(3)LinearRegression
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X_train, y_train)
