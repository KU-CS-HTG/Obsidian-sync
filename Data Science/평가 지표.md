1: 분류
(1)ROC_AUC
임계값을 분석하기 위해 도입한 곡선
from sklearn.metrics import roc_auc_score
roc_auc = roc_auc_score(y_val, pred[:, 1])
문제 정의에 따르면 50000달러 미만일 확률이 높을 수록 0에 가깝고, 그 반대는 1에 가까움

(2)Accuracy
전체 데이터 중 올바르게 예측된 데이터의 비율
코드는 위 코드에서 roc_auc 부분을 accuracy로 바꾸면 됨

(3)Precision
정밀도는 양성으로 예측된 데이터 중 실제로 양성인 비율이다 
from sklearn.metrics import precision_score
precision = precision_score(y_true, y_pred)
precision = precision_score(y_true_str, y_pred_str, pos_label='A')
문자 형태의 target을 사용할 때에는 뭐가 양성인지 pos_label로 지정해줘야 함

(4)Recall
재현율은 실제 양성인 데이터 중 모델이 양성으로 올바르게 예측한 비율이다
코드는 위의 코드에서 precision 부분을 recall로 바꾸면 됨

(5)F1-Score
정밀도와 재현율의 조화평균으로 정의되는 평가지표로, 높을 수록 좋음
from sklearn.metrics import f1_score
f1 = f1_score(y_val, pred, pos_label = '>50K') 

2: 회귀
(1)MSE(Mean Squared Error)
실제값과 예측값의 차이를 제곱해 평균한 값
from sklearn.metrics import mean_squared_error
mse = mean_squared_error(y_true, y_pred)

(2)MAE(Mean Absolute Error)
실제값과 예측값의 차이에 절댓값을 씌운 값
코드는 위의 코드에서 mean_squared_error를 mean_absolute_error로 바꾸기

(3)결정 계수(R-squared)
회귀식이 얼마나 잘 데이터를 설명하는지 나타내는 지표
코드는 위의 코드에서 mean_squared_error를 r2_score로 바꾸기

(4)RMSE(Root Mean Squared Error)
MSE에 제곱근을 적용한 값
코드는 위의 코드에서 mean_squared_error 앞에 root_를 붙여주면 됨

(5)MSLE(Mean Squared Log Error)
실제값과 예측값의 로그를 취한 후 차이를 제곱해 평균한 값
코드는 위의 코드에서 mean_squared_error를 mean_squared_log_error로 바꿔주면 됨

(6)RMSLE(Root Mean Squared Log Error)
MSLE에 제곱근을 취한 값
코드는 위의 코드에서 mean_squared_error를 root_mean_squared_log_error로 바꿔주면 됨

(7)MAPE(Mean Absolute Percentage Error)
예측값과 실제값 사이의 오차를 백분율로 나타낸 것
mape = (abs((y_true - y_pred) / y_true)).mean() X 100
